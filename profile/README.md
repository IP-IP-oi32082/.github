<h2>美国住宅地址的定价，被三件事推高</h2>
<p>美国是跨境业务需求最集中的市场，也是住宅地址价格最高的地区之一。价格高的原因不是「美国资源少」，而是三件事叠加：需求集中、优质供给受限、以及独享要求普遍。</p>
<p>理解这三点，才能判断一个报价是「市场价」还是「明显异常」。</p>

<h2>收费的四种口径</h2>
<p>口径一，按条按月。最常见，适合长期固定使用。口径二，按条按年。单价更低，但灵活性差。口径三，按流量。适合间歇性使用，视频类业务不适用。口径四，套餐制。含固定数量地址与带宽，超出另计。</p>
<p>四种口径的数字不能直接比较。比价前先统一口径，否则比的是不同的东西。</p>

<h3>套餐制要看的三项</h3>
<p>包内含几条、含多少带宽、超出如何计。三项不清楚的套餐，实际成本往往高于按条购买。</p>
<h3>为什么续费价常高于首期价</h3>
<p>获客成本被压进了首期。这不是欺骗，但必须提前知道。做年度预算时按续费价算，才不会在第二个月发现超支。</p>

<h2>影响单价的具体变量</h2>
<p>一，州与城市。纽约、洛杉矶等需求集中地更贵。二，运营商。主流运营商报价更高，小型运营商便宜但历史记录可能复杂。三，独享程度。独享比共享贵数倍。四，租期。长约单价低。</p>
<p>四个变量里，第三个对体验影响最大。省下的钱往往以返工的形式还回去。</p>

<h2>预算怎么定</h2>
<p>按「经营主体数」定数量，不按店铺数。每个主体一条，加一到两条备用。单价按目标地区的市场区间估，再乘租期。</p>
<p>另外留一笔试错预算，用于验证新供应商。没有试错预算，就只能一直用现有供应商，即使质量下降也无法更换。</p>

<h2>怎么判断报价是否合理</h2>
<p>三项检查。一，是否明显低于同类普遍水平。低太多要问成本优势来源。二，是否愿意提供地址段或归属说明。拒绝提供的，多为多层转售。三，条款是否完整，尤其是更换、退款、续费。</p>
<p>三项都异常的，基本可以判断资源来源不明。三项都正常的，价格高一点也值得考虑。</p>

<h2>成本之外的三个隐性支出</h2>
<p>第一，试错成本。低价资源频繁更换，每次都要重新适应环境。</p>
<p>第二，迁移成本。地址不可用时迁移，涉及重配与观察期，效率损失常高于月费。</p>
<p>第三，管理成本。地址多了，记录与巡检的工作量上升。</p>

<h2>一个实用的换算：按店铺产出比定预算</h2>
<p>与其纠结一条地址的单价高低，不如算一个比值：这条地址的月成本，占它服务的那个店铺月毛利的多少。占比很低时，单价高低无关紧要，稳定性才是重点；占比很高时，说明业务模型还没跑通，此时更该优化商品与流量，而不是在地址上省钱。这个换算能把「贵不贵」从主观感受变成可讨论的数字，也能避免在小钱上反复内耗。</p>
<p>换算还有一个附带好处：它逼你把「一条地址服务哪些店铺」先理清楚。理不清的，往往就是隔离设计有漏洞的地方。</p>
<h2>常见问答</h2>
<h3>美国住宅比欧洲贵吗</h3>
<p>常见情况下接近或略高，取决于城市与运营商。不能一概而论。</p>
<h3>便宜的一定不能用吗</h3>
<p>不是。规模效应与地区优势能带来真实低价。关键是能测出来，而不是只能听说明。</p>
<h3>能按月买吗</h3>
<p>多数支持。首次合作建议按月，跑满一个周期再决定是否长租。</p>
<h3>价格含设备吗</h3>
<p>多数纯地址方案不含设备。需要运行环境要另选或自备。</p>
